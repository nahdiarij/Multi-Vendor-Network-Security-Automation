# Project Documentation

This directory contains the technical documentation of the Multi-Vendor Network Security Architecture and Automation project.

## Documentation Structure

### Architecture
Contains network architecture diagrams and infrastructure topology.

### Design Documents
Contains High-Level Design (HLD) and Low-Level Design (LLD) documents.

### Screenshots
Contains screenshots illustrating the implementation, configurations, and security validation.

## Project Components

- Multi-layer network architecture
- Cisco and Fortinet security solutions
- Infrastructure automation using Terraform and Ansible
- Intrusion detection validation using Snort
